# 战斗浮动数字可见性设计

## 目标

让伤害、受伤与治疗数字在战斗状态刷新后仍完整可见，解决当前战斗界面重绘提前销毁浮字的问题。

## 方案

在 `#scene-battle` 外建立一个固定定位的战斗特效层。每次结算后，浮字按目标战斗单位的屏幕位置加入该层；后续调用 `renderApp()` 只替换战斗场景内容，不会影响已经开始播放的特效。

伤害、受伤与治疗分别保留现有红色、橙色、绿色语义。字号提高至约 `2.4rem`，加入深色描边/阴影，并将上浮淡出动画设为 `1.6s`。动画结束后移除对应节点，避免残留。

## 边界与测试

不改变战斗伤害、治疗或 API 结算规则；仅改变表现层。前端结构测试会验证特效层、独立挂载方式与 `1.6s` 动画时长。手工验证应确认刷新血条后浮字不会闪退。
