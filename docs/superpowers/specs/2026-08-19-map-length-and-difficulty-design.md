# 25 层地图与难度曲线设计

## 目标

将当前流程过短、前期敌人无压力的 12 层全连接地图，升级为一局约 20–30 分钟的 25 层局部连接肉鸽路线。普通、精英与英雄战斗必须持续消耗 HP，并使装备、篝火、事件和 CTF 利用链成为击败蒙多的必要构筑过程。

## 地图拓扑

- 地图共 25 层；第 1 层只有起点，第 25 层只有 Boss。
- 第 2–24 层每层 2–4 个节点：前期通常 2 个，中期 3 个，后期 3–4 个。
- 每个节点仅连接下一层 1–2 个空间相邻节点；生成器不得产生一层对下一层的全连接。
- 路线可合流，也可出现只通向风险收益的分支；不存在“所有资源都能一次拿完”的必经路线。
- 保证从起点到 Boss 至少有一条可达路径，且这条路径上按顺序包含英雄、商店、篝火。生成器可在其他位置生成同类节点，但受局部边限制。
- 事件、普通、精英、英雄、商店和篝火按阶段加权抽取；第 25 层固定 Boss。

## 三阶段敌人强度

敌人根据所在楼层取得 `tier = floor // 6`，基础敌人类型再加上以下成长：

| 阶段 | 楼层 | 小兵 HP / 攻击 / 护甲 | 野怪 HP / 攻击 / 护甲 | 英雄 HP / 攻击 / 护甲 |
| --- | --- | --- | --- | --- |
| 生存 | 2–6 | 900 / 420 / 25 | 1,600 / 720 / 60 | 3,600 / 1,050 / 95 |
| 构筑 | 7–16 | `900 + 260*tier` / `420 + 110*tier` / `25 + 15*tier` | `1600 + 420*tier` / `720 + 170*tier` / `60 + 20*tier` | `3600 + 650*tier` / `1050 + 240*tier` / `95 + 25*tier` |
| 压榨 | 17–24 | 同上再乘 HP 1.25、攻击 1.3 | 同上再乘 HP 1.35、攻击 1.35 | 同上再乘 HP 1.45、攻击 1.4 |

所有数值取整。当前基础剑魔面对小兵可获胜但会持续掉血；精英和英雄需要合理使用 W/E/R、篝火或构筑。Boss 蒙多既有 32000 HP、5000 攻击、200 护甲及低血量机制保持不变。

## 经济与 CTF 链兼容

- 每场战斗胜利由服务端立即结算金币，战斗结果响应必须包含 `gold_reward`；前端在胜利摘要中显示“获得 X 金币”。
- 战斗奖励按敌人阶段递增：小兵 `700 + 250*tier`、野怪 `1400 + 400*tier`、英雄 `3000 + 700*tier`。普通节点使用小兵奖励，精英节点使用野怪奖励，英雄节点使用英雄奖励。
- 非 Boss 战斗胜利后，`runs.gold` 必须增加本场 `gold_reward`；Boss 不掉落金币，仍只在胜利时显示 Flag。
- 英雄奖励竞态仍是大量金币与刷新券的来源；批量购买逻辑漏洞、篝火 SQLi 取得暗裔契约均不改变。
- 事件不提供海克斯；海克斯仍仅来自篝火冥想。

## 前端与验收

- 地图 UI 保持逐层布局，能清楚显示 25 层及局部连接关系；不可达节点禁用。
- API 地图快照提供每一节点的楼层与边关系，前端不假设固定节点 ID 或固定楼层。
- 测试覆盖 25 层、节点数量范围、无相邻层全连接、主链存在、分层敌人难度、每类战斗胜利的金币结算，以及 Docker 求解器仍能获得 Flag。

## 自检

- 无占位符或歧义的地图长度、连接数量、敌人成长与奖励公式。
- 局部连接与“保证一条英雄→商店→篝火→Boss 主链”不冲突。
- 未修改蒙多机制、海克斯来源或三条预期 CTF 漏洞链。
