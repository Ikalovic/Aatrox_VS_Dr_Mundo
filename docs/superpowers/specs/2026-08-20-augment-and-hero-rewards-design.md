# 海克斯效果与英雄战利品设计

## 目标

让篝火选择的海克斯立即且可见地影响角色，且让每个英雄节点在胜利后提供可领取的战利品；同时保留本题 SQL 注入、竞态与批量购买构成的预期利用链。

## 海克斯效果

`stats()` 除装备和锻造碎片外，读取已选择海克斯并累加效果：吞噬灵魂 +800 生命、全能龙魂 +60 攻击、歌利亚巨人 +1200 生命、艾卡西亚的陷落 +35 护甲、回归基本功 +30 攻击、扇巴掌 +15 攻击、牙仙子 +600 生命、逃跑计划 +10 护甲。暗裔契约仍只由 Boss/Q3 逻辑读取。

掷骰狂人在选择时立即添加 2 张刷新券，并创建 3 次免费锻造资格。锻造资格会在商店中显示，优先消耗资格而不扣金币；耗尽后沿用现有 750 金币锻造流程。

## 英雄战利品

每个已击败的英雄节点可领取一次，正常奖励是 1500 金币和 1 张刷新券。英雄战斗胜利后前端立即展示专属结算面板；领取成功后返回地图继续路线。领取记录键使用英雄节点 ID，防止不同英雄节点互相占用。

领取实现仍按“检查该节点是否领取过 → 竞争窗口等待 → 发放奖励 → 写入领取记录”执行，刻意保留同一节点并发请求可重复发奖的竞态条件。前端错误提示只改善正常玩家体验，不改变接口与窗口。

## 验证与范围

自动测试覆盖海克斯属性、掷骰狂人的刷新券与锻造资格、按节点领取的英雄奖励及并发重复发奖。前端测试覆盖英雄胜利结算与可读错误提示。不会增加新的海克斯来源、改变暗裔契约概率/效果，或修复 SQL 注入与竞态漏洞。
