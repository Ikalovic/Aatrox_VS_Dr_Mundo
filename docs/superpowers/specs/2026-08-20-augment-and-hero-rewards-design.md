# 海克斯效果与英雄战利品设计

## 目标

让篝火选择的海克斯立即且可见地影响角色，且让每个英雄节点在胜利后提供可领取的战利品；同时保留本题 SQL 注入、竞态与批量购买构成的预期利用链。

## 海克斯效果

公共海克斯以 750 金币锻造器作为价值锚点：银色约 1500、金色约 2200、棱彩约 3500 金币价值。银色为回归基本功（+60 攻击）、牙仙子（+1200 生命）与逃跑计划（+30 护甲）。金色为灵魂虹吸（+25% 吸血）、巨人杀手、艾卡西亚的陷落（+65 护甲）与钢化你心（+2200 生命）。棱彩为全能龙魂（+140 攻击）、歌利亚巨人（+4000 生命）、双刀流（+100 攻击，Q/W 命中后敌方下一次攻击 -20%）与掷骰狂人。

巨人杀手的增伤随敌方当前生命相对玩家最大生命线性增长：当敌方当前生命达到玩家最大生命的 120% 时，伤害提升封顶为 70%；低于该阈值时按比例递增。灵魂虹吸的 25% 吸血与装备吸血、E 的临时吸血相加。

所有生命型海克斯同时增加等额当前生命，且封顶于更新后的最大生命。掷骰狂人在选择时立即添加 2 张刷新券，并创建 3 次免费锻造资格；资格优先消耗且不扣金币。前端会立即提示该奖励，在属性栏和商店显示剩余次数；有资格时商店按钮显示“免费锻造（剩余 N）”，耗尽后恢复 750 金币。暗裔契约仍只由 Boss/Q3 逻辑读取，维持隐藏、0.0000001% 正常概率与必要通关定位。

## 英雄战利品

每个已击败的英雄节点可领取一次，正常奖励是 1500 金币和 1 张刷新券。英雄战斗胜利后前端立即展示专属结算面板；领取成功后返回地图继续路线。领取记录键使用英雄节点 ID，防止不同英雄节点互相占用。

领取实现仍按“检查该节点是否领取过 → 竞争窗口等待 → 发放奖励 → 写入领取记录”执行，刻意保留同一节点并发请求可重复发奖的竞态条件。前端错误提示只改善正常玩家体验，不改变接口与窗口。

## 验证与范围

自动测试覆盖海克斯属性、掷骰狂人的刷新券与锻造资格、按节点领取的英雄奖励及并发重复发奖。前端测试覆盖英雄胜利结算与可读错误提示。不会增加新的海克斯来源、改变暗裔契约概率/效果，或修复 SQL 注入与竞态漏洞。

## 地图手绘标记

地图画布上方提供独立的透明标记层，包含“绘制”“擦除”“清空标记”三个操作。标记层在绘制/擦除模式时接收指针输入，在普通浏览模式完全不拦截节点点击。笔迹序列化到浏览器本地存储，键包含本局 run ID，因此刷新页面后保留、开始新远征后自动使用新的空白标记；不发送到服务端，也不影响地图边、节点或 CTF 接口。
