# Aatrox_VS_Dr_Mundo

中等难度校赛 Web CTF。启动：`FLAG='flag{real_flag}' docker compose up --build`，访问 `http://localhost:8080`。

每队部署独立容器。真实 Flag 仅通过环境变量传入，源码中的默认 Flag 仅用于本地开发。题目仅限授权比赛环境使用。

玩法：在 25 层局部连接的分支路线中逐层前进；战斗失败即本局失败。敌人和掉落金币会随楼层成长。篝火只能选择休息或冥想，海克斯只会从冥想候选中获得；英雄节点战胜后可领取奖励，商店支持属性锻造器和批量购买。

属性面板会展示生命、攻击、护甲与吸血。饮血剑提供的吸血可以叠加；使用 E 后，接下来三回合造成伤害还会额外获得 30% 吸血。

事件节点会提供一次性的收益或风险抉择，例如金币、刷新券、属性强化，或牺牲生命换取属性；事件不会提供海克斯。

提示：随机不代表只能等待；冥想候选从哪里来；奖励先打钱还是先记账；收银员数的是种类还是件数。
